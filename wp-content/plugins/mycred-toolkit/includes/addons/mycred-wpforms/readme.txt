== Description ==

myCRED wpforms integration add-on allows you to reward users on multiple form submission events.

== myCRED wpforms integration Features ==
Here are the most notable features of myCred myCRED wpforms integration.

**Submit Form event hooks**
- Award points to users when they submit a form;
- Award points to users when they submit a specific form;

**Submit Specific Field Value event hooks**
- Award points to users when they submit a specific field value;

**Submit Specific Field Value On Specific Form event hooks**
- Award points to users when they submit a specific field value on a specific form;


== Installation ==

1. Go to Plugins > Add New.
2. Under Search, type myCRED wpforms integration
3. Find myCred myCRED wpforms integration and click Install Now to install it
4. If successful, click Activate Plugin to activate it and you are ready to go.
