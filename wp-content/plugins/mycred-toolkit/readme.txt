== Installation ==

= From WordPress backend =

1. Navigate to Plugins -> Add new.
2. Click the button "Upload Plugin" next to "Add plugins" title.
3. Upload the downloaded zip file and activate it.

= Direct upload =

1. Upload the downloaded zip file into your `wp-content/plugins/` folder.
2. Unzip the uploaded zip file.
3. Navigate to Plugins menu on your WordPress admin area.
4. Activate this plugin.

== Frequently Asked Questions ==

= What happened to the Individual addons of myCred? =

All myCred addons have come under one roof called myCred Toolkit. So now, you will get one complete package of all myCred modules

= Do I need myCred plugin to use myCred Toolkit? =

myCred Toolkit is an extension of myCred plugin. So, you need to download myCred first and then install myCred Toolkit.

= Can I disable unused Toolkit modules? =

Yes! You can disable those Toolkit modules that you don’t require.

= Do I need to keep myCred Toolkit and myCred Toolkit Pro active to work effectively? =

If you need advanced myCred addons, then myCred Toolkit Pro is for you. If you only need basic features, myCred Toolkit will be enough. If you need both basic and advanced functionalities, only then you need to keep both toolkits active.
